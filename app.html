PrintfWhy

Type a C printf format and its arguments. See exactly what it prints, and what each %-spec did.

Checked against gcc 11.4 and glibc printf on 34,318 generated formats made of d i u o x X c s specs with random flags, width, precision, * and length modifiers (6 fresh seeds): 0 differences on the 13,852 formats whose behaviour the C standard defines. The other 20,466 use flag combinations the standard leaves undefined (for example %#d or %05s); there the engine also matched glibc every time, but another C library may print something else. The rules follow the cppreference page for fprintf, which was fetched. Not covered: %f %e %g %a %p %n and wide characters (explained, not computed), the C locale, and escapes like \n (type them as characters). Type sizes assume a 64-bit Linux build (int is 32 bits, long is 64). Everything runs in your browser.
